## 二、部署拓扑

- 服务器：腾讯云 `159.75.67.99`（Ubuntu 24.04），项目目录 `/home/ubuntu/yanban-ai`。
- 应用服务：`server.py` 由 systemd 托管（`yanban-api.service`），监听 `127.0.0.1:8001`，开机自启、崩溃自动重启。
- 反向代理：宿主机 nginx 在主域名下以 `/robot/` 子路径同源反代到 8001（学生/教师页、`/robot/api/`、静态资源白名单），与主站（考研小程序 React 应用）共用 HTTPS 证书，互不干扰。
- 数据：`/home/ubuntu/yanban-ai/data`（SQLite + WAL、上传资料、文档索引），数据库迁移在启动时自动执行。
- 配置：全部经 `/home/ubuntu/yanban-ai/.env` 注入（生产模式 `YANBAN_LOCAL_TEST_MODE=0`、CORS 固定为 `https://xiaoeduhub.online`、限流 120 次/分/IP）。

## 六、建议验收路径

1. 学生端注册新账号 → 我的档案填写信息 → 提交专业课申请。
2. 教师端令牌登录 → 学生档案中通过申请（也可试驳回并填写原因，学生端会显示该原因）。
3. 学生端上传一份 txt/md 资料 → 查看解析状态；发起分析 → 观察"失败但保留原因、可重试"的诚实状态（模型额度恢复前）。
4. 复习规划生成计划（无模型也有确定性计划）→ 带背/刷题/自测/总结空态与引导。
5. 教师端：学生搜索/筛选、学习详情、重新分析、纸质资料包状态流转、健康与审计历史。
6. 手机（或 390px 模拟器）检查底部导航与主要页面。
