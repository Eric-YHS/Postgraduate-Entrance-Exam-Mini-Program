以下命令不启动服务、不连接网络、不安装依赖。契约测试使用临时 `YANBAN_DATA_DIR`、临时 SQLite 和临时上传目录；不会读写项目 `data/` 中的业务数据库或上传资料。

```bash
cd /path/to/专业课AI机器人
python -m py_compile server.py tests/test_server_contracts.py scripts/verify_local.py
python -m unittest discover -s tests -p 'test_*.py' -v
python scripts/verify_local.py
```


## 本轮新增代码契约

- 资料上传先校验扩展名、声明 MIME 和 PDF/DOCX/图片文件签名；解析失败写入 `parse_failed`，扫描 PDF/图片在无视觉模型时诚实写入 `needs_ocr`。`/api/materials/retry` 只重试原文件，不删除原输入。
- `course_analysis_runs` 先写入 `running`，模型异常、空结果或来源引用越界写入 `failed`；只有新结果完成引用校验并完整入库后才归档旧知识/题库/背诵结果。
- 课程通知带 `course_key`，读取与已读操作按学生和课程双重过滤；服务端缓存已锁定院校画像，普通学生刷新不重复联网，显式刷新才生成新证据会话。
- 教师端提供生产管理员 token 验证、资料共享审批队列及健康/关键审计历史；审计记录过滤 token、API key、password、secret 等字段。
- 学生端所有学习写请求显式携带 `Authorization` 和 `courseKey`；教师端敏感管理 API 均通过管理员 token。
- 纸质资料包状态机覆盖 `incomplete/ready/partial/printing/printed/shipped/failed`，非法流转被服务端拒绝并返回中文原因；每次流转写入 `paper_package_status_history`，教师端列表展示最近流转记录；生成失败/部分生成的资料包不会被标成待打印。
- `POST /api/admin/analysis/rerun` 供教师对指定学生+课程触发重分析：身份、删除/停用状态和课程 entitlement 全部由服务端校验，失败只影响新 run 并保留旧结果，成功写入 `audit_log`。
- `GET /api/admin/students/{id}/detail` 返回单学生的档案、entitlement、资料（含解析状态与失败原因）、按课程分组的分析 run（含失败 error）和知识/背诵/题库计数；不包含其他学生数据（有契约测试）。
- 教师端学生表格支持文本搜索和课程/账号/资料三组前端筛选，刷新后保持；「学习详情」视图与既有「任务详情」并存，重分析按钮在等待期禁用、失败显示服务端原因。
- 学生端课程申请被驳回时在首页、档案和申请页展示教师填写的具体原因（无原因时明确提示），并引导修改后重新申请。
- 计划任务 key 以稳定条目 id（`recite-/practice-` 等）为优先来源，同一天同一任务 key 不变，服务端对 id 形 key 做归属校验；计划卡片展示任务动作与完成标准（completionCriteria）。
- 分析中心展示真实 run 状态条：进行中轮询、失败显示截断原因并可重试、完成显示时间、资料删除后提示 stale；不凭知识条目数量伪装完成。
- 带背会话真实落库：开始调 `/api/recite/session/start`（同日幂等），退出调 pause，重新进入 resume，今日队列完成调 finish；会话调用失败时明确提示且不伪造暂停状态。
- 学生端知识页提供「导出导图结构」，导出当前课程在线导图的结构化 JSON（节点/关系/详情/版本元数据）；教师纸质资料包仍不在学生端提供。
