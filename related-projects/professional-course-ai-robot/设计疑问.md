# 研伴 AI 全站设计疑问

请根据下面的问题，对此前的《研伴 AI 全站 UI/UX 像素级设计规范书（最终执行版）》进行统一补充和确认。

这些问题不是要求你重新设计一套风格，而是希望你把目前描述不足、业务含义不清、页面状态不完整、数据来源不明确和开发落地存在歧义的地方一次性说明清楚。

请按照问题编号逐条回答。对于尚未确定、当前系统不支持或不应加入本期开发的内容，请明确写出“暂不支持”“删除该设计”或“作为后续功能”，不要用模糊表述代替结论。

## 一、总原则与设计稿的执行级别

### 1. 这份设计稿的执行级别是什么？

请明确选择一种：

- 作为视觉方向参考，允许开发时根据现有页面和业务调整；
- 作为交互和布局规范，页面结构原则必须执行，但尺寸允许微调；
- 作为像素级最终规范，尺寸、颜色、间距和组件状态都必须严格执行。

如果不同部分的执行级别不同，请按“颜色、字体、布局、交互、动效、页面尺寸、移动端”分别说明。

### 2. 当设计稿与现有业务逻辑、接口、数据结构冲突时，优先级如何排列？

请明确以下顺序：

- 现有业务逻辑；
- 用户已经确认的产品规则；
- 现有 API 和数据结构；
- 本设计稿的视觉方案；
- 后续新增功能建议。

如果设计稿中出现当前系统没有的数据或功能，是否允许直接删除该设计，而不是要求新增后端接口？

### 3. 请区分本期必须实现、可以调整和暂不实现的内容。

请将设计稿中所有页面和功能分为：

- 本期必须实现；
- 本期保留视觉位置，但功能可暂时不可用；
- 后续功能，不纳入本期开发；
- 设计稿误写，应删除。

## 十一、纸质资料包和打印预览

### 47. 打印资料目录是否必须完整包含五个固定部分？

请确认打印预览和最终 HTML 目录都必须包含：

1. 思维导图；
2. 完整知识手册；
3. 需要背诵的知识点；
4. 学生上传的试题及课后题汇总；
5. 完整 AI 训练题册。

还要明确未来追加的静态资料如何编号、排序、显示来源和标注生成状态。

### 48. 纸质资料包哪些内容绝对不能出现？

请确认打印版明确排除：

- 每日学习总结；
- 每周/每月学习总结；
- 动态复习计划；
- 自测结果；
- 批改结果；
- 错题过程；
- 学习进度记录；
- 教师提示词；
- AI 模型配置；
- API Key 和其他内部信息。

### 49. 教师是否可以修改纸质资料包内容？

请明确教师是否可以：

- 调整目录顺序；
- 删除某个部分；
- 选择是否打印追加部分；
- 添加教师批注；
- 修改封面；
- 重新生成单个部分。

如果不允许修改，请删除编辑类按钮，只保留查看、打开打印版、下载 HTML 和状态更新。

### 50. “打开打印版”“下载 HTML”“确认打印”分别做什么？

请逐项说明：

- 打开打印版是否直接进入浏览器打印预览；
- 下载 HTML 是否只下载文件；
- 点击确认打印是否自动修改状态；
- 打开但没有真正打印时状态如何处理；
- “已打印”由系统自动判断还是教师手动选择；
- “已寄出”是否需要填写物流信息；
- 是否保留打印时间和寄出时间。

### 51. 纸质资料包状态流转是什么？

请给出完整状态机，包括：

- 待打印；
- 打印中；
- 已打印；
- 已寄出；
- 生成失败；
- 可选追加部分失败。

请明确哪些状态可以回退、哪些状态不可回退、每次变化是否记录时间和操作人。

### 52. A4 预览尺寸是屏幕尺寸还是打印尺寸？

请明确：

- 屏幕预览比例；
- `@page` 纸张尺寸；
- 打印边距；
- 页眉页脚；
- 多页分页规则；
- 打印时是否隐藏操作栏；
- 是否支持浏览器原生打印；
- 下载 HTML 后是否可以脱离系统直接打印。

### 53. 打印按钮为什么使用玫红色？

请确认玫红色代表：错误、待处理、高优先级、打印动作还是教师端主操作。

如果玫红色同时表示解析失败和确认打印，会产生语义冲突。请重新确认打印按钮、错误状态和待处理状态的颜色语义。
