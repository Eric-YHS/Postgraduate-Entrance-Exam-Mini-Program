# 考研督学平台项目状态档案

> 本文件记录项目当前真实状态，不是产品愿景或需求清单。每次重大修改后必须同步更新。
>
> 最后更新：2026-08-18

## A. 项目概况

- 项目名称：考研督学平台
- 项目类型：React Web App + Fastify API + PostgreSQL
- 当前版本：开发中，生产加固阶段
- 当前环境：本地开发/测试；生产资源尚未完整接入
- 当前阶段：核心业务可运行，持续进行数据持久化、AI 边界、生产安全与体验收敛
- 项目目标：为教师和考研学生提供可审计、可扩展、可部署的课程、学习计划、任务、自测、入学测评、订单权益和社区管理系统

## B. 技术栈

- 前端：React 19、Vite 6、lucide-react、KaTeX、SheetJS xlsx
- 后端：Node.js、Fastify 5、Zod
- 数据库：PostgreSQL
- 认证：Argon2id、JWT、HttpOnly Cookie
- ORM：无；使用参数化 SQL
- Storage：Storage adapter；当前 local 驱动，云对象存储驱动待接入
- AI：前端存在监管机器人配置与提示词草案；API/生产模式已禁止浏览器保存模型凭证和机器人配置，但后端 Provider/Orchestrator 尚未完成；演示模式仅用于本地预览
- Agent Runtime：尚未完成统一 Runtime
- 部署：Dockerfile、docker-compose、Nginx/部署文档和迁移脚本已具备，生产联调未完成

## C. 页面与入口

前端当前以 `src/App.jsx` 为主要应用入口，使用角色入口、pathname 识别和 page 状态切换页面。已存在的主要功能包括：

- 学生端：首页、课程、商品/购买、自测、入学测评、学习计划与任务、测评档案、工具、代学、题目辅导、社区、账户与密码
- 教师端：工作台、学员管理、课程与内容、商品与订单、计划管理、题库与试卷、入学测评、社区审核、知识库、带背后台、监管机器人、系统设置
- 公共入口：登录、注册、公开登记、考试分享链接、入学测评入口

当前状态：主要业务页面可进入；完整统一路由、嵌套路由、详情页 URL 和浏览器 Back 仍需逐步补强，不能视为已完成。

## C.1 代学题库与计时学习

- 已实现：导入使用事务、幂等键和审计；题目列表不返回答案或解析。知识库上传内容与代学题库保持独立，尚未设计合并能力。

- 待完成：`012` 尚未在真实 PostgreSQL 执行，尚未进行实际浏览器会话、权限隔离与并发幂等集成验收；因此不得描述为已完成生产验收。

## E. 数据结构与 Migration

当前迁移包括：

- `001_initial.sql`：账号、学生、登记、入学分发/提交、课程、课程资源、权益、订单、审计日志
- `002_production_integrity.sql`：迁移历史、外键、唯一约束、金额与日期约束、索引
- `003_learning_core.sql`：计划模板、学生计划、任务完成、日周月自测、社区帖子、学习事件
- `004_entrance_assessment_core.sql`：入学题库、试卷、题目快照、错题、学科分数
- `005_course_commerce_core.sql`：课程定价、商品、订单索引、待处理订单与有效权益约束
- `006_idempotency_keys.sql`：幂等请求记录、处理状态与响应缓存
- `007_idempotency_principals.sql`：将幂等键改为按调用主体隔离的复合主键，防止跨账号响应复用
- `008_learning_preferences_and_events.sql`：学生报考科目、学习偏好、休息日及学习事件扩展字段
- `009_ai_runtime_foundation.sql`：AI 机器人注册表与 AI 任务状态、输入输出、审批、Provider 引用和成本字段基础

核心业务数据原则上以 PostgreSQL 为真实来源。学员科目、休息日和自测推送已有受限读写 API；任务结构编辑、AI 调整历史和部分计划进度仍存在前端 localStorage 遗留或 API hydration 缺口，尚未达到完全云端闭环。
