考研督学系统 · 产品系统大纲 V1.0 · 2025年6月

附录：需求沟通要点总结

一、核心功能需求（10+1 模块）

  • 直播授课：小程序内直播（主）+ 视频号直播（辅）
  • 录播课程：直播自动转存 + 手动上传，章节制管理
  • 课程分类：公共课（政/英/数）+ 专业课（按专业方向分栏）
  • 题库系统：上传历年真题，三种刷题模式（政治选择+英语单词+数学公式匹配）
  • 免费学习板块：文字资料 + 免费视频，免费学员开放
  • 付费学员专区：专属每日学习计划 + 推送 + 进度提醒
  • 论坛社区：学生发帖 + 老师答疑，AI自动审核内容
  • 个性化复习计划定制：机构预设 → 基础匹配 → 智能调整
  • 创业/宣传板块：想做博主的同学报名加入宣传团队
  • 新人7天免费体验：新注册7天内畅享全部付费功能
  • 错题本：自动收集错题，针对性复习

二、付费与权益体系

  • 三层权益：🟢免费（刷题+免费板块+答疑机器人）→ 🟡7天体验（全功能限时）→ 🔴付费（5大机器人+专属计划+全部功能）
  • 付费模式：单科购买 + 全科打包，非订阅制，价格后台可调

三、后台管理系统（10 大菜单）

  • 数据看板 → 内容管理 → 学员管理 → 题库管理 → 知识库/语料库 🆕 → 消息模板管理 🆕 → 论坛管理 → 机器人管理 → 创业板块 → 系统设置
  • 新增：知识库用于AI投喂参考资料；消息模板自定义督学推送格式
  • 客服通知：学生报名后自动汇报给总账号
  • 角色权限：超级管理员 / 普通老师 / 客服，不同权限
  • 内容同步：网页端新建/编辑 → 小程序端自动同步上架

四、企业微信机器人体系

  • 免费引流：免费注册 → 添加免费答疑机器人企微 → 问基础问题 → 引导报班
  • 付费自动拉群：报名成功 → 自动创建服务群（学生+指定老师+指定机器人）
  • 建群采集：机器人自动提问并归档学员信息到后台
  • 5大机器人：⏰督学（8:00推送/到点提醒/22:00检查） + 💬解答（三层应答：预设→AI→搜索） + 🎯择校 + 📝自测（每半月AI出卷） + 🧭全程规划（数据整合动态调整）
  • 预留扩展：支持后续新建更多机器人
  • 通用能力：预设答案优先 → AI搜索兜底；对话记录后台可查；老师可人工介入

五、三端协同数据流

  • 后台上传内容 → 数据库 → 小程序同步上架
  • 企微机器人服务记录 → 数据库 → 后台可查看管理
  • 小程序学习行为 → 数据库 → 督学/规划机器人获取数据
  • 后台设置学习计划 → 数据库 → 督学机器人按时推送
  • 全程规划数据流：老师预设路线 → 学生学习数据（自测+督学+答疑） → AI分析 → 动态增补调整
