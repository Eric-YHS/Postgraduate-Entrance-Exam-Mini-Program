## 二、详细任务

### C-01 企业微信 API 接入基础

**需求**：接入企业微信官方 API，实现通讯录管理、群机器人、消息推送。

**现状**：代码中只有微信小程序订阅消息 `wxPush.js`，无企业微信相关代码。

**实现建议**：
1. 新增 `src/services/wecom.js`：
   - 获取企业微信 access_token 并缓存。
   - 封装发送应用消息、群机器人消息、创建群聊、邀请成员接口。
2. `config.js` 新增环境变量：
   - `WECOM_CORP_ID`
   - `WECOM_AGENT_ID`
   - `WECOM_SECRET`
   - `WECOM_WEBHOOK_KEY`
3. `.env.example` 同步更新。

**涉及文件**：`src/services/wecom.js`、`src/config.js`。

**验收标准**：
- 可成功获取企业微信 access_token。
- 可向指定用户发送应用消息。

### C-02 知识库/语料库（RAG）

**需求**：AI 机器人的知识底座，支持上传考研政策、院校分数线、FAQ、真题解析等资料。

**实现建议**：
1. 新增 `knowledge_bases` 表：`title`、`description`、`category`、`created_by`、`created_at`。
2. 新增 `knowledge_documents` 表：`base_id`、`title`、`file_path`、`file_type`、`status`、`created_at`。
3. 新增 `knowledge_chunks` 表：`document_id`、`content`、`embedding`（TEXT 存 JSON 数组或 Base64）。
4. 文档解析：PDF/Word/TXT 提取文本，按段落切分 chunk。
5. Embedding：调用大模型 API（如通义千问/DeepSeek）获取向量，或使用本地轻量模型。
6. 检索：用户提问时计算问题向量，与 chunk 向量 cosine 相似度排序，取 Top-K。
7. 后台管理页：上传资料、查看解析状态、测试问答。

**涉及表**：`knowledge_bases`、`knowledge_documents`、`knowledge_chunks`。

**验收标准**：
- 后台可上传 PDF/Word/TXT 资料。
- 提问能检索到最相关的资料片段。
- 检索结果可用于生成回答。

### C-03 消息模板管理后台

**需求**：后台可配置督学机器人每天发送的消息格式与内容。

**实现建议**：
1. 新增 `message_templates` 表：
   - `code`（如 `morning_plan`、`due_reminder`、`evening_check`）
   - `name`、`content`（支持变量如 `{name}`、`{time}`、`{subject}`）
   - `channels`（企微/站内/微信订阅）
   - `is_active`、`updated_by`、`updated_at`
2. 后台管理页：模板列表、编辑、预览、测试发送。
3. 督学机器人发送消息时从数据库读取模板并替换变量。

**涉及表**：`message_templates`。

**验收标准**：
- 后台可编辑早安计划、到点提醒、晚间检查三类模板。
- 模板修改后机器人即时生效。

### C-04 免费答疑机器人（引流转化）

**需求**：免费学员添加企业微信答疑机器人，回答基础考研问题，并引导报班。

**实现建议**：
1. 企业微信接收用户消息 webhook：`POST /api/wecom/message`。
2. 机器人处理流程：
   - 步骤 1：知识库 RAG 检索（C-02）。
   - 步骤 2：若未命中，调用大模型 API 生成回答。
   - 步骤 3：若问题超范围或表露报班意向，转人工客服/发送报名链接。
3. 回答中适当植入转化话术：
   - “这个问题在付费课程中有详细讲解。”
   - “付费学员可享受一对一解答。”
4. 限制回答范围：考研政策、考试科目、院校信息、报名流程等基础问题。

**涉及文件**：`src/services/wecom.js`、新增 `src/services/bots/freeTutorBot.js`。

**验收标准**：
- 免费用户添加企微机器人后可获得基础问题回答。
- 敏感/超范围问题引导报班或转人工。

### C-05 付费自动拉群

**需求**：学生付费报名后，自动创建专属服务群（学生 + 指定老师 + 指定机器人）。

**实现建议**：
1. 支付成功后（B-12）触发拉群逻辑。
2. 调用企业微信“创建群聊”接口，群名如 `{学生姓名}·考研专属服务群`。n3. 邀请学生、1-N 位老师、5 大机器人入群。
4. 机器人自动发送欢迎消息并开始采集信息（目标院校、专业、当前进度）。
5. 将群信息和成员关系存入 `wecom_groups` 表。

**涉及表**：`wecom_groups`、`wecom_group_members`、`users`、`orders`。

**验收标准**：
- 支付成功后 10 秒内自动建群并邀请成员。
- 机器人欢迎语正常发送。

### C-06 督学机器人

**需求**：在付费学员群内/私信中，按学习计划执行 8:00 推送、到点提醒、22:00 检查。

**实现建议**：
1. 复用 `src/services/scheduler.js` 定时任务，新增企业微信消息发送。
2. 早晨 8:00：读取该学员当日 `tasks`，用模板生成学习计划消息，私聊发送。
3. 到点提醒：每分钟检查任务 `start_time`，匹配时发送“该学 XX 科目了”。
4. 晚间 22:00：列出当日所有时段完成状态，询问完成情况。
5. 学生回复后，解析“完成/未完成”，更新 `task_completions` 或自定义存档表。
6. 仅对 `tier='paid'` 学员执行。

**涉及表**：`tasks`、`task_completions`、`user_entitlements`、`message_templates`。

**验收标准**：
- 付费学员每天收到 3 类督学消息。
- 回复完成情况可被机器人识别并记录。

### C-07 解答机器人（三层应答）

**需求**：付费群内解答机器人，采用“预设答案库 → AI 生成 → 联网搜索”三层应答。

**实现建议**：
1. 第一层：知识库 RAG 检索，命中即返回预设答案。
2. 第二层：未命中时调用大模型 API（通义千问/DeepSeek），基于上下文生成回答。
3. 第三层：涉及最新政策/分数线时，调用搜索引擎 API（如 Bing/SerpAPI）获取实时信息后生成回答。
4. 支持输入类型：文字、语音（转文字）、图片（OCR）、文档（PDF/Word 提取）。
5. 对话记录存入 `ai_conversations`（需先在 `db.js` 创建该表）。

**涉及文件**：`src/services/bots/answerBot.js`、`src/services/ai.js`。

**验收标准**：
- 常见问题优先使用知识库回答。
- 复杂问题调用大模型，实时问题调用联网搜索。
- 支持文字/图片/文档提问。

**涉及表**：`knowledge_chunks`、`users`。

**验收标准**：
- 学生可咨询院校与专业选择。
- 回答基于知识库和最新搜索数据。

### C-09 自测老师（每半月 AI 出卷）

**需求**：每半个月自动生成自测试卷，监督学生提交并批改。

**实现建议**：
1. 新增 `ai_exams` 表：`student_id`、`title`、`question_ids`、`generated_at`、`due_at`、`status`。
2. 新增 `ai_exam_submissions` 表：`exam_id`、`answers`、`score`、`submitted_at`。
3. 定时任务：每半月为每位付费学员生成一份试卷。
   - 题目来源：学生近期学习内容、错题、薄弱知识点标签。
   - 使用大模型根据错题和薄弱点出题，或从题库 `questions` 中智能抽题。
4. 在群内推送自测链接，学生在线答题。
5. 客观题自动批改，主观题可 AI 辅助批改。
6. 未按时提交自动提醒，超 N 天未交通知老师。

**涉及表**：`ai_exams`、`ai_exam_submissions`、`practice_records`、`questions`。

**验收标准**：
- 每半月自动生成自测试卷。
- 学生答题后自动出分并生成薄弱点报告。

### C-10 全程规划老师（学情周报）

**需求**：整合老师预设路线、自测结果、督学完成情况、答疑记录、刷题正确率，生成学情周报与调整建议。

**实现建议**：
1. 新增 `study_reports` 表：`student_id`、`week_start`、`data_json`、`suggestions`、`created_at`。
2. 每周日凌晨生成上周报告：
   - 输入：任务完成率、学习时长、做题数与正确率、错题标签分布、自测成绩、答疑问题。
   - 输出：已掌握知识点、薄弱环节、下周建议。
3. 使用大模型生成自然语言建议（Prompt 中注入上述数据）。
4. 报告同步给老师和学生（企微群 + 站内通知）。

**涉及表**：`study_reports`、`task_completions`、`practice_records`、`ai_conversations`、`ai_exam_submissions`。

**验收标准**：
- 每周自动生成学情周报。
- 报告包含掌握点、薄弱点、下周计划建议。

### C-12 AI 答疑助手（小程序/站内）

**需求**：学生在小程序或 Web 端做错题后可追问 AI 获得详细讲解。

**实现建议**：
1. 在 `ai_conversations` 表创建后，新增 API：
   - `POST /api/ai/ask`：通用答疑。
   - `POST /api/ai/explain-question`：针对某道题目讲解。
   - `POST /api/ai/study-plan`：生成学习计划。
   - `POST /api/ai/summarize`：对帖子/资料生成摘要。
2. 调用大模型 API，Prompt 中注入题目内容、学生历史记录、知识库检索结果。
3. 小程序端在题目解析页增加“问 AI”按钮。
4. Web 端在论坛帖子页增加“AI 摘要”按钮。

**涉及表**：`ai_conversations`、`questions`、`forum_topics`、`knowledge_chunks`。

**验收标准**：
- 学生可向 AI 提问并获得讲解。
- 对话历史可在个人中心查看。

### C-14 客服人工介入机制

**需求**：机器人无法处理或用户要求人工时，可转接客服老师。

**实现建议**：
1. 用户发送“人工”、“客服”、“转人工”等关键词时，机器人停止自动回复，通知客服进群或私聊。
2. 后台机器人对话记录页增加“人工接管”按钮，客服点击后接管该会话。
3. 接管期间机器人不自动回复，客服老师直接回复。
4. 客服释放会话后恢复机器人自动回复。

**涉及表**：`ai_conversations`、`wecom_groups`、`users`。

**验收标准**：
- 用户可触发人工介入。
- 客服可在后台接管会话。
