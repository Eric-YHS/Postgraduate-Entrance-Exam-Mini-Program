## 二、详细任务

### A-01 题库英语单词题型模式

**需求**：展示英文单词 + 音标，给出 4 个中文意思选项（1 正确 + 3 干扰项），选择后显示正确答案。

**现状**：所有题目共用通用 A/B/C/D 单选 UI（`public/student-practice.js`、`miniprogram/pages/practice/practice.js`）。

**实现建议**：
1. 在 `questions` 表新增 `display_mode` 字段，枚举：`radio`（默认政治选择）、`word`（英语单词）、`formula`（数学公式）。
2. 干扰项生成：从同 `subject` 下其他题目/词汇卡片的 `back_content` 中随机抽取 3 个。
3. Web 端：在 `student-practice.js` 中根据 `display_mode` 渲染不同模板。
4. 小程序端：在 `practice.js/practice.wxml` 中新增单词题模板。
5. 解析区展示：音标、例句、词根词缀（复用 `flashcards.phonetic`、`example_sentence`、`word_root`、`affix`）。

**涉及表**：`questions`、`flashcards`。

**验收标准**：
- 教师创建题目时可选择“英语单词”题型。
- 学生端看到单词 + 音标 + 4 个中文选项。
- 答题后显示正确中文释义与例句。

### A-02 题库数学公式匹配题型

**需求**：显示公式左边，给出 4 个右边选项，学生选择匹配项。

**实现建议**：
1. 复用 `questions.display_mode = 'formula'`。
2. 题干支持 Markdown/LaTeX 或图片；选项以图片/文本混排展示。
3. 若使用 LaTeX：Web 端可引入 KaTeX，小程序端使用 base64 图片或 MathJax 渲染（建议先用图片占位）。
4. 公式图片上传：复用 `questionUpload` 到 `uploads/question/`。

**涉及表**：`questions`（新增 `display_mode`、`formula_image_path` 等可选字段）。

**验收标准**：
- 教师可上传公式题干图片和选项图片。
- 学生端按“公式匹配”布局展示。
- 提交后显示正确答案。

### A-03 错题本“已掌握”移除

**需求**：学生可标记错题为“已掌握”，从错题本移除，不再纳入错题重做/智能复习。

**现状**：`wrong_review_schedule` 表已有 `is_done` 字段，缺 `mastered`。

**实现建议**：
1. 新增 `wrong_review_schedule.is_mastered INTEGER DEFAULT 0`。
2. 新增 API：`POST /api/practice/wrong/:questionId/master`。
3. 查询错题列表时过滤 `is_mastered = 1`。
4. Web 端 `student-practice.js` 错题 Tab 增加“已掌握”按钮。
5. 小程序端错题页同步增加按钮。

**涉及表**：`wrong_review_schedule`、`practice_records`。

**验收标准**：
- 点击“已掌握”后该题不再出现在错题本。
- 可在历史记录中查看已掌握题目。

### A-05 小程序端论坛楼中楼回复

**需求**：小程序端回复支持 `reply_to_id`，对回复进行回复。

**现状**：Web 端 `topic-detail.js` 已实现嵌套回复树，小程序 `detail.js` 只传 `content`。

**实现建议**：
1. `miniprogram/pages/forum/detail.js` 回复表单增加 `replyToId`、`replyToUser`。
2. 点击“回复”按钮时记录目标回复 ID 和作者名。
3. `detail.wxml` 按树形结构展示嵌套回复（最多 2 级）。
4. 调用已有 API：`POST /api/forum/topics/:id/replies`（需确认后端已支持 `reply_to_id`）。

**涉及表**：`forum_replies`。

**验收标准**：
- 小程序端可回复某条具体回复。
- 嵌套关系正确展示。

### A-06 小程序端论坛图片/视频/附件上传

**需求**：小程序发帖和回复支持图片、视频、附件。

**现状**：小程序 `post.js`/`detail.js` 只提交文本。

**实现建议**：
1. 发帖页使用 `wx.chooseMedia` 选择图片/视频，`wx.chooseMessageFile` 选择附件。
2. 将文件通过 `wx.uploadFile` 上传到后端（复用 `forumUpload`，字段名 `images`、`videos`、`attachments`）。
3. 提交帖子时附带已上传文件路径数组。
4. 后端 `forum.js` 已支持这些字段，无需大改。

**涉及 API**：`/api/forum/topics`、`/api/forum/topics/:id/replies`。

**验收标准**：
- 小程序发帖可上传 9 张图、1 个视频、3 个附件。
- 帖子详情正确渲染媒体与附件下载链接。

### A-09 论坛 AI 自动审核

**需求**：帖子/回复发布前自动检测敏感词和违规内容。

**现状**：完全空白，只有人工举报审核 `content_reports`。

**实现建议**：
1. 建立敏感词库表 `sensitive_words(word, level, category)`，或先硬编码基础词库。
2. 在 `POST /api/forum/topics` 和 `POST /api/forum/topics/:id/replies` 中增加审核逻辑。
3. 命中敏感词：可自动拦截或标记为“待审核”。
4. 预留 AI 审核钩子，未来接入大模型内容安全接口。

**涉及表**：`forum_topics`、`forum_replies`、`content_reports`（可选新增 `sensitive_words`）。

**验收标准**：
- 发布含敏感词内容时被拦截或进入待审核。
- 管理员可在后台查看待审核内容。

### A-10 直播自动转存录播

**需求**：直播结束后自动生成回放，学生可观看。

**现状**：直播结束后仅更新 `status='ended'`，无录制文件。

**实现建议**：
1. WebRTC 服务端录制方案（推荐）：
   - 使用 `recordrtc` 或 `MediaRecorder` 在教师端浏览器录制音视频 Blob。
   - 结束直播时上传 Blob 到服务器 `uploads/course/`。
   - 生成 `folder_items` 记录，类型 `video`，关联到默认“直播回放”文件夹。
2. 数据库增加 `live_sessions.recording_path`。
3. 小程序/ Web 端在直播详情显示“观看回放”按钮。

**涉及表**：`live_sessions`、`folder_items`、`folders`。

**验收标准**：
- 直播结束后 30 秒内生成回放记录。
- 学生可点击观看回放。

### A-11 课程章节制管理

**需求**：课程支持章节/分 P，类似 B 站。

**现状**：`courses` 和 `folder_items` 是平级记录，无章节层级。

**实现建议**：
1. 新增 `course_chapters` 表：`course_id`、`title`、`sort_order`。
2. `folder_items` 增加 `chapter_id` 字段。
3. 教师端 `teacher.js` 课程管理增加“章节”编辑。
4. 学生端课程详情页按章节分组展示视频列表。
5. 播放页左侧显示章节列表，支持快速跳转。

**涉及表**：`course_chapters`、`folder_items`、`courses`。

**验收标准**：
- 教师可为课程创建章节并拖拽排序。
- 学生端按章节展示课程视频。

### A-12 课程试看机制

**需求**：支持设置前 N 节免费试看，后续仅付费学员可见。

**实现建议**：
1. `folder_items` 增加 `is_free_preview INTEGER DEFAULT 0` 和 `sort_order`。
2. 学生端课程详情页根据用户权益等级判断是否显示“试看”/“锁定”。
3. 播放接口 `/api/courses/:id` 增加权限校验：非免费且未付费返回 403 并提示解锁。
4. 需配合 B 负责人的“三层权益体系”完成权限中间件。

**涉及表**：`folder_items`、`users`（权益字段）。

**验收标准**：
- 免费用户只能播放标记为试看的章节。
- 付费用户可播放全部章节。

**需求**：课程按公共课（政/英/数）和专业课方向分栏展示。

**现状**：只有 `subject` 自由文本字段。

**实现建议**：

4. 小程序/ Web 端课程页顶部显示“公共课 | 专业课”Tab，专业课下再按方向二级分栏。

**涉及表**：`course_categories`、`courses`。

**验收标准**：
- 课程可按公共课/专业课两级分类浏览。
- 后台可增删改分类。
