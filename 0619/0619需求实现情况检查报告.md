# 0619 考研督学系统需求实现情况检查报告

> 对照文件：`考研督学系统_架构图(5).html`、`考研督学系统_详细设计(5).html`  
> 检查日期：2026-06-19  
> 代码版本：main 分支当前快照

---

## 一、总体结论

当前系统已完成一个**功能丰富的考研学习小程序/网页后台 MVP**，覆盖任务管理、题库刷题、错题本、论坛社区、商城、直播、录播网盘、学习统计、成就系统等大量功能。

但与 0619 设计方案中的**商业化督学体系**相比，仍有明显差距。差距主要集中在：

1. **企业微信机器人体系**（5 大机器人、自动拉群、知识库 RAG）几乎空白；
2. **三层权益体系**（免费 / 7 天体验 / 付费）未建立；
3. **后台管理菜单**仅实现最基础的用户/注册审核，未覆盖内容、学员、题库、论坛、机器人、系统设置等；
4. **直播/课程**缺少自动转存录播、视频号接入、章节制、试看机制；
5. **题库**缺少英语单词、数学公式匹配等专门题型模式。

## 四、建议实施优先级

### 第一期（1-2 周）：补齐高优先级缺口

1. **扩展后台管理菜单**：在现有 `admin.html/admin.js` 中增加内容管理、题库管理、论坛管理、系统设置入口。
2. **题库专门题型**：新增题目类型字段，前端根据类型渲染政治选择/英语单词/数学公式三种 UI。
3. **错题本“已掌握”**：新增 `mastered` 状态，前端增加移出错题本按钮。
4. **小程序论坛完善**：补齐楼中楼回复、图片上传、收藏、话题标签。
5. **用户权益体系**：新增 `user_entitlements` 表或 `users` 权益字段，实现免费/体验/付费校验中间件。

### 第二期（2-4 周）：商业化核心链路

1. **7 天体验专区**：新用户自动体验、到期降级、倒计时提醒。
2. **付费学员专区**：专属计划与推送绑定权益等级。
3. **课程章节制与试看**：新增 `chapters`/`sections` 表，支持前 N 节免费试看。
4. **直播自动转存录播**：服务端录制直播流并生成 `folder_items` 回放。
5. **管理后台数据看板**：补齐活跃度、完成率、营收、机器人数据指标。

### 第三期（1-2 个月）：企业微信机器人与 AI

1. 接入企业微信 API，实现自动拉群。
2. 建设知识库/语料库（RAG）。
3. 开发 5 大机器人：督学、解答、择校、自测、规划。
4. 实现学情周报、AI 答疑、AI 出卷。

## 六、备注

- 当前系统以 **Express + SQLite + 原生 HTML/JS + 微信小程序** 构建，0619 方案建议的技术栈（NestJS/FastAPI + MySQL/PostgreSQL + Redis + 腾讯云）尚未切换。
- 0619 方案中的 **“三端协同”**（小程序 + 后台 + 企业微信）目前只完成了小程序 + 后台两端，企业微信端完全缺失。
- 如需进一步针对某一模块输出详细实现计划，可基于本报告继续拆分任务。
