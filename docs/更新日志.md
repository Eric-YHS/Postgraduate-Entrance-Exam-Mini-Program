# 更新日志

## v2.1.0 (2026-06-14)

### 新功能

- **AI 智能助手**：AI 答疑、AI 生成题目、AI 学习摘要
- **错题智能复习**：自动收集错题，按遗忘曲线安排复习
- **模拟考试系统**：教师组卷、学生模考、自动评分与成绩分析
- **拼团购买**：资料商城支持多人拼团，降低学习成本
- **举报与内容审核**：帖子/评论举报、管理员审核流程
- **习惯追踪与打卡**：每日学习习惯记录与连续打卡统计
- **考研倒计时**：首页显示考试倒计时，支持自定义目标日期
- **关注与粉丝系统**：学生/教师互相关注，构建学习社群
- **成就系统扩展**：新增词汇、专注、早起等多维度成就
- **学习数据统计**：总览/周报/月报、科目正确率、标签分析

### 工程改进

- 修复数据库迁移中索引先于表创建导致的初始化失败
- 修复商城下单/购物车结算的并发超卖风险（BEGIN IMMEDIATE 事务）
- 修复 WebSocket 直播聊天未定义变量导致的进程崩溃风险
- 修复课程文件夹 parentId 的 SQL 注入风险
- 修复任务创建主任务与子任务不在同一事务的问题
- 统一 Web 端任务链接 URL 协议白名单校验，防止 javascript: XSS
- 生产环境强制校验 SESSION_SECRET 长度（≥32 字符）
- 增加 .dockerignore，优化 Docker 镜像构建
- 重构 GitHub Actions 部署流程：增加测试阶段、数据库备份、健康检查
- Nginx 配置支持 HTTPS、HSTS、80→443 重定向
- 引入 Jest + Supertest 集成测试，覆盖认证、商城、工具函数

### 文档更新

- 更新数据库设计文档，补充 15+ 张新增表
- 更新 README API 路由列表
- 更新服务器运维文档，移除明文密码

## v2.0.0 (2026-04-13)

### 新功能

- **超级管理员系统**：新增 admin 角色，教师注册审核，用户管理后台
- **题库分类**：按科目/题型/参考书分类，自定义标签系统
- **录播视频网盘**：无限层级文件夹，类似网盘的浏览体验
- **论坛增强**：支持图片/视频/附件上传和链接分享
- **艾宾浩斯词汇记忆**：SM-2 算法，四档评分，类似百词斩/不背单词
- **练习会话**：综合/按科目/错题重做模式，记录练习进度
- **学生维度视图**：教师端按学生查看任务完成情况
- **任务完成追踪**：学生可标记任务完成，教师可查看完成率
- **晚间推送提醒**：每晚 22:00 自动提醒未完成任务
- **微信订阅消息**：小程序推送通知支持
- **统一 Excel 模板**：任务/题目/用户/词汇四种标准模板

### Bug 修复

- 修复退出登录后 Bearer Token 仍有效的问题
- 修复 /api/auth/me 每次刷新新建 Token 的问题
- 修复小程序直播入口无法进入直播页的问题
- 修复 GBK CSV 导入静默失败的问题
- 修复任务允许结束时间早于开始时间的问题
- 修复正确答案可以不存在于选项中的问题
- 修复商城下单允许小数数量的问题
- 修复回复不存在的帖子返回 500 的问题
- 修复操作不存在的直播间返回成功的问题
