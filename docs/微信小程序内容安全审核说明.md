# 微信小程序内容安全审核说明

本项目的论坛发布和回复属于 UGC。审核版本必须真实调用微信官方内容安全接口，禁止在接口失败时回退成本地敏感词并继续公开内容。

## 平台与服务器前置配置

1. 在生产服务器 `/home/ubuntu/kaoyan-xiaochengxu/.env` 配置：

   ```dotenv
   WX_APP_ID=wx27fca32a9ddfdc8e
   WX_APP_SECRET=<微信公众平台生成的 AppSecret>
   CONTENT_SECURITY_PUBLIC_BASE_URL=https://xiaoeduhub.online
   ```

2. 在微信公众平台将服务器出口 IP `159.75.67.99` 加入接口 IP 白名单。
3. 将 `https://xiaoeduhub.online` 同时加入小程序的 `request` 与 `uploadFile` 合法域名。
4. 不得把 AppSecret、access_token 或内容安全会话 Token 录入代码、GitHub 或审核录屏。

## 审核版调用链

- 新帖正文、话题标签和附件名称调用 `msgSecCheck`，参数固定为 `version=2`、`scene=3`，并使用当前访问用户真实 `openid`。
- 每张图片先调用同步 `imgSecCheck`，再调用 `mediaCheckAsync`；微信原始返回值和 `trace_id` 会保存到 SQLite 的 `content_security_checks` 表。
- 回帖与楼中楼回复同样调用 `msgSecCheck`。
- 接口超时、配置缺失、IP 白名单错误、`review` 或 `risky` 均失败关闭，不公开内容。
- 微信异步接口只支持图片和音频。含视频或普通附件的帖子会标记为待人工审核，并从公开列表过滤。

## 录屏步骤

1. 打开小程序【我的】→【设置】→【内容安全检测记录】。
2. 点击【调用 msgSecCheck】，录制页面出现 `errcode=0`、`errmsg=ok`、`suggest=pass` 及已保存的原始返回值。
3. 点击【选择图片并调用两项接口】，选择正常图片。
4. 录制 `imgSecCheck` 返回 `errcode=0`，以及 `mediaCheckAsync` 返回 `errcode=0` 和非空 `trace_id`。
5. 再录制【论坛】→【发布】的完整服务流程，画面需包含三项 API 状态和发布结果。
6. 将上述录屏、内容安全记录页截图、发帖成功截图上传至微信公众平台，再提交代码审核。

`mediaCheckAsync` 的 `errcode=0` 仅表示异步任务提交成功，页面会显示“已提交异步检测”，不会误标成“已通过”。
